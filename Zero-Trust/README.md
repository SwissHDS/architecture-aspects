# Worum geht es

Der Datenraum Gesundheit SwissHDS muss gegen Angriffe wie z.B. DDOS Attacken aus dem Internet geschützt werden. 

Ein integraler Bestandteil des Schutzkonzeptes ist die Zero Trust Architektur mit Mechanismen zur Erkennung und 
Unterdrückung von Angriffen und damit verbundenem unautorisierten Zugriff auf Daten mit Schutzbedarf. In den 
Basisdiensten des IAM müssen dazu an geeigneten Stellen Schnittstellen zur Erkennung von anomalem Zugriffsverhalten 
implementiert werden.

Das Architekturteam des Datenraums hat dazu ein Konzept mit den wichtigsten Anforderungen und einen Umsetzungsvorschlag 
zusammengestellt. Das Konzept schlägt Schnittstellen und Komponenten als Ergänzung des SwissHDS IAM vor, welche die 
erforderlichen Massnahmen zur Erkennung und Unterdrückung von anormalen Verhalten implementieren. 

Das Konzept konzentriert sich auf die Schnittstellen und Komponenten. Die statistischen Methoden zur Erkennung 
werden im Nachgang untersucht in einem separaten Dokument beschrieben und zur Diskussion gestellt.

Die Dokumente dazu finden Sie im
Ordner [SwissHDS Zero Trust](https://github.com/SwissHDS/architecture-aspects/tree/main/Zero-Trust) auf dieser Plattform.
