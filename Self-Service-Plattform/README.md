# Worum geht es

Im Datenraum müssen Datenprodukte und die Zugangsbedingungen von den Teilnehmern gefunden werden können. Den 
Teilnehmern im Datenraum muss dazu eine Plattform bereitgestellt werden, welche in Analogie zu Data Mesh Architekturen 
als Self-Service Plattform bezeichnet wird.

Die Self-Service Plattform stellt verschiedene Services zur Verfügung, insbesondere: 
- Data Product Registry als Verzeichnis der Datenprodukte und deren Zugangsbedingungen,
- API zur Registrierung von Datenprodukten und den Zugangsbedingungen durch die Datenbereitsteller,
- API zur Abfrage von Datenprodukten und deren Zugangsbedingungen durch die Datennutzer,
- Ein Zugangsportal mit Web Benutzeroberflächen zum Management der Einwilligungen und der Vorbereitung der Sekundärnutzung

Das SwissHDS Architekturteam hat dazu ein Konzept sowie die wichtigsten Anforderungen zusammengestellt. Das Konzept 
beschreibt den geplanten Aufbau, die angebotenen Services und die eingesetzten Standards der Self-Service Plattform. 

Die Dokumente dazu finden Sie im Ordner [Self Service Plattform](https://github.com/SwissHDS/architecture-aspects/tree/main/Self-Service-Plattform) auf dieser Plattform.
