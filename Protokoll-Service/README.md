# Worum geht es

Die Kommunikation von Personendaten im Datenraum Gesundheit muss die gesetzlichen Vorgaben für die Protokollierung erfüllen. Dazu soll ein zentraler Dienst entworfen werden, welche von allen Applikationen im Datenraum Gesundheit (Swiss HDS) für die Protokollierung gemäss der «Verordnung für den Datenschutz» (Datenschutzverordnung, DSV) vom 31. August 2022 genutzt werden kann.

Das Architekturteam des Datenraums hat dazu ein Konzept sowie die wichtigsten Anforderungen zusammengestellt. Die Dokumente dazu finden Sie im Ordner [Protokoll Service](https://github.com/SwissHDS/architecture-aspects/blob/main/Protokoll-Service/SwissHDS-Protokoll-Service.pdf) auf dieser Plattform.

Gerne erwarten wir Ihr Feedback und Ihre Anregungen.
